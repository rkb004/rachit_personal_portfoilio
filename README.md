# Rachit Bandaram — Portfolio

React + Vite portfolio deployed with GitHub Actions to GitHub Pages.

## Local development

```bash
npm install
npm run dev
```

## Customize

- Edit `PROFILE` at the top of `src/main.jsx` for your email, LinkedIn, and Light the Hoan video URL.
- Add your resume PDF to `public/resume.pdf` (the Resume link will not work until you do).
- Update the experience and project text in `src/main.jsx` as needed. Confirm metrics and descriptions before publishing.
- Replace the illustrated bridge with your actual competition media when ready.

## Deploy

Push to `main`. In GitHub repository Settings → Pages, set Source to **GitHub Actions**. Your URL will be https://rkb004.github.io/rachit_personal_portfoilio/ .
